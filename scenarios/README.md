# Behavior scenarios

The files in this folder specify the behavior of the apps in this repository as Gherkin scenarios, written from the user's point of view. The conventions live in starkeep-core's [scenarios/README.md](https://github.com/starkeep-org/starkeep-core/blob/main/scenarios/README.md).

## Files

| File | ID prefix | Covers |
|---|---|---|
| [photos-library.md](photos-library.md) | `PHOTOS-LIB-` | Photos on the web: the library grid, selection, the viewer, captions, deleting, and Settings |
| [photos-sharing-and-cloud.md](photos-sharing-and-cloud.md) | `PHOTOS-SHARE-` | Albums, public links, what a visitor sees, and cloud-served Photos |
| [photos-people.md](photos-people.md) | `PHOTOS-PEOPLE-` | Face recognition, the People view, and sharing names with other apps |
| [photos-import-and-processing.md](photos-import-and-processing.md) | `PHOTOS-IMPORT-` | Adding photos, previews, the details read from each file, and processing |
| [photos-mobile.md](photos-mobile.md) | `PHOTOS-MOB-` | Photos on the phone: sign-in, the library, the viewer, and Settings |
| [photos-mobile-sync.md](photos-mobile-sync.md) | `PHOTOS-MOBSYNC-` | Photos on the phone: camera-roll imports, background backup, and the phone's own previews |
